
# Пожертвования от зрителей

Пожертвования (далее — донаты) являются основным источником очков для лотов. Кроме того, именно через донаты чаще всего формируются и сами лоты.
В процессе работы с аукционом большая часть времени уделяется обработке донатов.

## Интеграции

Для приёма донатов необходимо настроить интеграцию с платёжными системами в настройках аукциона.

На текущий момент поддерживается подключение **Donation Alerts**. В будущем количество доступных интеграций будет расширяться.

## Обработка пожертвования

После успешной настройки интеграции все поступающие донаты отображаются в разделе «Пожертвования» панели навигации.
Основой обработки является донат-код, который пользователь указывает в тексте сообщения

### Донат-код

Донат-код предназначен для идентификации лота, к которому пользователь хочет добавить очки, или для создания нового лота.
Код генерируется на странице просмотра лотов аукциона и имеет следующий формат:
- 8 символов;
- начинается с символа #;
- в тексте доната заключается в квадратные скобки.

Пример донат-кода в донате: **_[#a1b2c3d4] Забираю этот лот!_**

### Статус обработки

Каждый донат получает один из статусов в зависимости от результата обработки:
- **Добавлено**. Донат успешно обработан: создан новый лот или начислены очки существующему.
- **Ожидание проверки**. Донат содержит код, но соответствующий лот был удалён или изменён до момента обработки, либо ещё не создан.
- **Нет данных**. В тексте доната отсутствует корректный донат-код, либо код не может быть распознан.
- **Отклонен**. Донат обработан, но его применение к аукциону отклонено
