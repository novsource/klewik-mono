
# Лоты в аукционе

Лоты являются основой проведения аукциона. В этом разделе описано их назначение, а также способы создания, редактирования и экспорта.

## Зачем нужны лоты

Лот — это базовый элемент аукциона. Проведение аукциона без лотов невозможно.

Каждый лот содержит:
- Название;
- Количество очков.

## Создание лотов

Чтобы добавить новые лоты:
- В панели навигации перейдите в раздел «Лоты».
- Нажмите кнопку «Создать лоты».
- В открывшемся окне заполните поля.

Условия создания следующие:
- За один раз можно создать не более 3 лотов. Для добавления следующих лотов необходимо повторно открыть окно создания.
- Название лота должно быть уникально
- Количество очков лота не может быть больше 1 000 000

Вы также можете удалить лоты которые вам не нравятся.

## Экспорт лотов

Система поддерживает экспорт лотов для использования на платформе <a href="www.pointauc.com">Pointauc</a>.

Чтобы выполнить экспорт:
- Находясь в разделе «Лоты», нажмите кнопку «Экспорт».
- В появившемся окне выберите целевую платформу.
- Нажмите кнопку «Экспортировать» для подтверждения.
