# Игры в аукционе

Для определения победителя используются игры. В аукционе доступны два варианта, каждый из которых может работать в двух режимах.

## Виды игр в аукционе

Всего в аукционе на выбор есть следующие игры:
-  <a href="/streamers/game.html#колесо">Колесо</a>
-  <a href="/streamers/game.html#карты-beta">Карты</a>

### Колесо

Классическое колесо фортуны. После прокрутки анимации лот, на который указывает стрелка, 
либо выбывает, либо становится победителем — в зависимости от выбранного режима. 
После завершения отображаются количество очков лота и его общая вероятность победы.

### Карты <Badge>Beta</Badge>

Игра, в которой ведущий или зритель выбирает карту из предложенных. 
Под выбранной картой скрывается лот. Результат (победа или выбывание) также определяется режимом. 
Отображается количество очков и вероятность победы лота.

## Режим игры

Вы можете выбирать между двумя режимами игр:
- **Классика**. Выпавший (или выбранный) лот объявляется победителем. Аукцион завершается сразу после выпадения.
- **Выбывание**. Выпавший лот исключается из дальнейшего участия. Аукцион продолжается, пока не останется последний лот, который и становится победителем.
 
Вы можете переключаться между режимами по ходу проведения аукциона.

## Отображение информации

После завершения игровой анимации (вращение колеса / выбор карты) аукцион показывает:
- количество очков выпавшего лота;
- общую вероятность победы этого лота (рассчитывается независимо от выбранного режима игры).
