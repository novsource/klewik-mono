# Создание аукциона

_Перед началом проверьте что вы находитесь в <a href="/streamers/#список-стримеров-с-доступом">списке стримеров</a>_


## Запуск нового аукциона

- На главной странице нажмите кнопку «Создать аукцион».
- Авторизуйтесь через Twitch.

## Если активный аукцион уже существует

Система допускает наличие только одного активного аукциона.При попытке создать новый аукцион в тот момент, 
когда у вас уже есть активный вам будет предложен выбор:
- перейти в текущий активный аукцион;
- создать новый аукцион.

<Caption variant="warning">
    Если вы выберете создание нового аукциона, текущий активный аукцион будет автоматически закрыт (до тех пор, пока вы не удалите его или в нём не определится победитель).
</Caption>
