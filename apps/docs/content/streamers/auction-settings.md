# Настройки аукциона

На данный момент в настройках всего две вкладки: **Аукцион** и **Интеграции**

## Вкладка "Аукцион"

Во данной вкладке имеется всего две опции:
- **Удалить аукцион**. Удаляет аукцион и делает его недоступным для просмотра. В отличие от обычного окончания аукциона, сразу удаляет страницу с просмотром лотов для зрителей;
- **Изменить правила аукциона**. Вы можете написать правила аукциона, которые будут отображаться на странице просмотра лотов для зрителей. Максимальное допустимое количество символов - **350**.

## Вкладка "Интеграции"

Здесь вы можете подключить интеграции к аукциону. На данный момент доступен только **Donation Alerts**.
