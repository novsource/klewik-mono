## О проекте
Данное приложение представляет собой аукцион, функционирующий на основе системы очков. Основная функциональность включает в себя возможность создания лотов, каждый из которых имеет установленную стоимость в очках

Механизм определения победителя реализован на вероятностной модели: чем большее количество очков выделяется участником на лот, тем выше его шанс на выигрыш. Финальное определение победителя происходит посредством игровой механики (проведения игры). Дополнительно приложение поддерживает механизм пожертвований (донатов), позволяя зрителям финансово поддерживать понравившиеся лоты.
